## README

# Events Microservise

Este projeto é um microserviço para gerenciar eventos.

## Objetivo

Centralizar a lógica de cadastro, consulta, atualização e remoção de eventos em uma aplicação independente e escalável.

## Funcionalidades

- Cadastro de eventos
- Listagem de eventos
- Consulta por ID
- Atualização de dados
- Exclusão de eventos
- Organização por responsabilidades de microserviço

## Estrutura do projeto

- `src/` - Código-fonte da aplicação
- `tests/` - Testes automatizados
- `docs/` - Documentação complementar
- `README.md` - Documentação do projeto

## Como executar

1. Clone o repositório
2. Instale as dependências
3. Configure as variáveis de ambiente
4. Inicie a aplicação
5. Acesse os endpoints definidos no serviço
